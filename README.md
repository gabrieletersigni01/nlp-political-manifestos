# NLP Analysis of Political Manifestos

## Objective
This project applies NLP techniques to analyze semantic similarity between political manifestos.

## Dataset
The dataset is derived from the Archelec corpus and focuses exclusively on the French legislative elections of 1988.

## Methods
- Text preprocessing
- Transformer-based embeddings (BERT)
- Cosine similarity
- Ranking of similar documents
- Visualization (heatmap, t-SNE)

## Results
- Documents with similar ideological content tend to have higher similarity scores.
- Embeddings capture semantic relationships beyond simple word overlap.
- Clustering suggests latent grouping of political discourse.

## Limitations
- Dataset limited to 1988 elections
- No fine-tuning performed
- Results depend on pretrained embeddings
