# NLP Analysis of Political Manifestos

This project applies NLP techniques to analyze political manifestos from the Archelec corpus.

## Methods
- Text preprocessing
- Semantic density
- TF-IDF
- Sentence embeddings
- Cosine similarity

## Results
- Embeddings outperform TF-IDF in capturing semantic similarity
- Semantic density highlights differences in linguistic richness

## Dataset
Dataset not included due to size.  
Place the dataset inside the `data/` folder before running.

Run the notebook in Google Colab or Jupyter.
